# 予約サイト＋予約管理ツール（納品用ひな形）

取引先のお店に納品できる、ネット予約のしくみです。

- **予約画面** `index.html`：お客様がプラン、人数、日にち（○△×のカレンダー）、時刻を選び、名前と電話番号を入れて送る
- **管理画面** `admin.html`：お店の人がパスコードで入る。できることは次のとおり
  - 予約の一覧を見る、さがす
  - 予約を確定する、キャンセルにする、来店済みにする
  - お店メモを書く
  - 電話で受けた予約を入れる
  - カレンダーを見る
  - 休業日と貸切を入れる
  - CSV を書き出す
- **保存先**：お店の Google スプレッドシート。月額料金はかかりません。メールの通知も Google から送ります

`config.js` の `apiUrl` が空のときは **お試しモード** で動きます。このモードではデータがブラウザの中にだけ保存され、見本の予約も入っています。営業や打ち合わせでお店に見せるときは、このままフォルダを開くか、どこかに置いて見せてください。管理画面のパスコードは `demo` です。

## フォルダの中身

| ファイル | 役割 | お店ごとに変えるか |
|---|---|---|
| `config.js` | 店名、電話、住所、色、フォント、プラン、注意書き | **変える** |
| `index.html` / `admin.html` | 予約画面と管理画面 | 変えない |
| `assets/` | 画面の動き、見た目、空き計算のルール（`core.js`） | 変えない |
| `gas/Code.gs` / `gas/Core.gs` | Google Apps Script に貼るサーバーのプログラム | 変えない |
| `tests/core.test.js` | 動作確認のテスト（`node tests/core.test.js`） | — |

## 納品の手順（1店あたり 20〜30分）

### 1. スプレッドシートを用意する（お店の Google アカウントで）
1. お店の Google アカウントで、新しいスプレッドシートを作ります。名前の例は「○○ 予約台帳」です。
2. メニューの **拡張機能 → Apps Script** を開きます。
3. はじめからある `コード.gs` の中身を全部消して、`gas/Code.gs` の中身を貼ります。
4. 左の「ファイル ＋」から **スクリプト** を追加します。名前は `Core` にして、`gas/Core.gs` の中身を貼ります。
5. 上のプルダウンで `setup` を選んで **実行** します。はじめは権限の確認が出るので「許可」を押します。「このアプリは確認されていません」と出たら、「詳細」→「（安全ではないページ）に移動」を選びます。
6. 実行ログに **管理画面のパスコード** が出ます。お店に伝えてください。忘れたときは `showPasscode` を、変えたいときは `resetPasscode` を実行します。

スプレッドシートには、次の3つのシートができます。
- **予約**：1行が1件の予約です。ここを直接見たり、直したりしてもかまいません。
- **設定**：席数、受付時刻、定休日、滞在時間、何時間前まで受け付けるか、確定のしかた、通知先メールなど。**お店の人がここで変えられます**。
- **休業日・貸切**：管理画面からも入れられます。

### 2. ウェブアプリとして公開する
1. Apps Script の右上の **デプロイ → 新しいデプロイ** を押します。
2. 種類は **ウェブアプリ** を選び、次のように設定します。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
3. **デプロイ** を押します。出てきた **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）をコピーします。

> プログラムを直したときは、**デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン「新しいバージョン」→ デプロイ** の順に進めます。こうすると、同じ URL のまま新しい内容になります。

### 3. config.js をお店に合わせる
- `apiUrl` に、2でコピーした URL を入れます。
- `shop`（店名、電話、住所、営業時間、お店のサイト、プライバシーポリシー）を入れます。
- `theme` の色とフォントを、お店のサイトに合わせます。
- `plans` にプランを入れます。`consult: true` にしたプランは「相談」として受け付けます。席は押さえないので、貸切や大人数の窓口に使います。
- `notes` に、予約画面の下に出す注意書きを入れます。

### 4. 公開する
`reserve-kit` フォルダ（`tests` は不要です）を、そのまま静的サイトとして置きます。
- 例1：お店のサイトの中に `/reserve/` として置く
- 例2：Netlify にフォルダごとドラッグ＆ドロップする

お店のサイトの「ご予約」ボタンから、`…/reserve/` にリンクします。
管理画面は `…/reserve/admin.html` です。お店の人のスマホのホーム画面に追加しておくと便利です。

### 5. 納品前の確認
- [ ] 予約画面から自分の名前で予約を1件入れ、スプレッドシートの「予約」に行が増えること
- [ ] 通知先メールに「新しいご予約」が届くこと。お客様のメールに受付メールが届くこと
- [ ] 管理画面で「確定にする」を押すと、確定メールが届くこと
- [ ] 休業日を1つ入れて、予約画面でその日が「休」になること
- [ ] テストの予約を、スプレッドシートから消すこと

## しくみ（知っておくこと）

- **空きの数え方**：同じ日で、時刻の差が「滞在時間」より短い予約の人数を合計し、「席数」から引きます。少なめに見積もるので、取りすぎは起きません。数えるのは「仮予約・確定・来店」の予約だけです。「相談」と「キャンセル」は数えません。
- **同時の予約**：サーバーで順番に受けます（LockService）。そのうえで、空きをもう一度確かめてから保存します。同じ席を2人が取ることはありません。
- **確定のしかた**：「お店が確認して確定」にすると、ネット予約は **仮予約** で入ります。お店が管理画面で確定します。「すぐ確定」にすると、ネット予約は最初から確定です。
- **個人情報**：予約画面に返すのは、日時と人数の合計だけです。名前や電話番号を見られるのは、パスコードを入れた管理画面と、スプレッドシートの持ち主だけです。
- **いたずら対策**：次の対策をしています。
  - 見えない入力欄（ロボットよけ）
  - サーバー側での入力チェック
  - パスコードを10分に20回まちがえると、しばらく受け付けない
  - `=` で始まる入力が、シートで式にならないようにする
- **Google の上限**：無料アカウントで送れるメールは 1日100通ほどです（Google Workspace はもっと多い）。予約の数が多いお店は、Workspace のアカウントで作ってください。
- **ほかの予約サイトとの関係**：ぐるなびや食べログなどの予約とは、空きが自動ではそろいません。次のどちらかの運用にしてください。
  - 席の一部だけをこのしくみに割り当てる（「設定」の席数を少なめにする）
  - ほかのサイトで入った予約を、管理画面の「予約を入れる」で入れる

## 直すときの注意
`assets/core.js` を直したら、同じ内容を `gas/Core.gs` にもコピーして、`node tests/core.test.js` を実行します。テストは、2つのファイルが同じかどうかも確かめます。
